# 给官网的素材：螺壳、首次运行、系统要求、各档实测、安装与卸载

给 luoke-community 用的素材（2026-10-15 首版，10-28 按 beta1 更新：名字、安装位置、联网、卸载）。数字以 `docs/experiments/` 为准，这里只摘。用户装的应用叫「螺壳」；"主控"只在讲内部分工时用（顶层 CONTEXT.md「对外怎么叫」）。

## 螺壳是什么（用户视角）

一个菜单栏小程序（「螺壳」），在里面开启邮件助手、输入法等应用。它管这台 Mac 上所有的本地模型：下载、加载、占多少内存、什么时候让路、什么时候休息。两个应用共用一份模型、一份记忆，所以不用装两遍、不会各占各的内存。用户不用挑模型：实验室按这台 Mac 的内存档位配好，每个选择都有实测。

- 菜单栏一个小符号：实心圆点 = 正常在用，半圆 = 后台已暂停，叹号 = 引擎有问题，虚线圆 = 后台进程没连上；点开能看到当前底座模型、正在做什么、后台状态和功耗档。
- 不常驻的东西：打分模型用完 30 秒就把显存缓冲还回去；大模型在 16 GB 机器上只在你不用电脑时加载。

（下表的数字和首次运行预检页说的是同一份：配方 `recipes/<发布号>.json` 的 `expectations` 块，出处 `docs/experiments/`；改数字只改那里。）

## 系统要求

- Apple 芯片的 Mac，macOS 26.2 以上（推理引擎里的 mlx 要求 26.2；螺壳本身 14 起，但没有引擎什么都做不了）。
- 内存 16 GB 起，推荐 32 GB 以上。各档的真实体验见下表；首次运行时螺壳也会按这台 Mac 的档位和芯片照实说。
- 磁盘：模型和引擎约 7 GB（16 / 32 GB 档）或 28 GB（64 GB 以上的档）。
- 装在「应用程序」（`/Applications`）；管理员账户直接拖进去，标准账户由系统问管理员授权（ADR 0012）。

## 各档实测（摘要，出处见 `docs/experiments/task-baselines-2026-10.md`、`coexistence-e2e.md`、`tier-bases.md`）

| | 16 GB | 32 GB | 64 GB 以上 |
|---|---|---|---|
| 底座模型 | Qwen3.5-9B 4-bit（5.8 GB） | 同左 | gemma-4-26B-A4B 8-bit（26 GB） |
| 邮件分拣（45 封评测集） | 39/45，每封约 22 秒（M1） | 39/45，每封约 11 秒（M4） | 44/45，每封约 2 秒（M5 Max） |
| 清理判断 / 订阅体检 / 了解你 | 38/40、25/25、13/14 + 5/8 | 同左 | 39/40、25/25、12/14 + 7/8 |
| 后台整理什么时候做 | 只在你不用电脑时，大模型现加载、用完就卸 | 大模型常驻，随时做 | 同左 |
| 输入法重排（打字时按前文选首选）⁽¹⁾ | 慢的机器退到小档：M1 上每键选好 150 / 183 ms（p50 / p90），首选准确率 88.8% | 基础款 M4 退到小档；Pro / Max 完整体验 | 完整体验：M5 Max 上每键选好 42 / 70 ms（p50 / p90），首选 89.8% |
| 从打字里归纳常用说法和话题 | 不支持（9B 在这一档没通过硬性评测） | 支持 | 支持 |

⁽¹⁾ 输入法的数归 luoke-ime，以它的 [docs/评测.md](https://github.com/luokelabs/luoke-ime/blob/main/docs/评测.md) 为准（d33af22）：用时是逐键打字（每 120 ms 一个键）时最后一个键到模型选好的那份候选，两格同一种测法；M1 经螺壳打分，M5 Max 经输入法的个人化组件在本机打分（同一台机器上两条路准确率逐条一样，用时只差几毫秒）。M5 Max 是 10-13 量的，之后加的「先答新键」只会让它一样快或更快。准确率是引擎总来得及时整句对的比例（每次跑结果一样，苹果自带的双拼这样测是 78.8%），对外说「约 90%」；想说慢机器上打字时实际上屏的首选，可以单独引 M1 小档、按空格前停 100 ms 的 88.0%。

"慢的机器"由螺壳实测决定（打分模型的探针 p90 超过 50 ms），不是按内存：基础款芯片约 60 ms、M1 约 135 ms 算慢，M5 Max 约 14 ms 不慢。

## 下载与安装

1. 在官网 [luoke.ai](https://luoke.ai) 下载螺壳的安装盘 `Luoke.dmg`（一个螺壳，在里面开启不同的应用）。
2. 打开 DMG，把螺壳拖进「应用程序」（`/Applications/螺壳.app`，ADR 0012）。第一次打开时 macOS 会问"这是从互联网下载的应用，确定打开吗"，点"打开"（已公证，会写明 Apple 已检查）。
3. 首次运行：看这台 Mac 是哪一档并照实说体验 → 勾选要装的应用 → 一屏说清要下载什么、多大 → 下载（分块、能续传、逐文件校验）→ 本机检查（模型能加载、能出合法格式、测本机速度）→ 注册登录项、启动应用。以后在菜单「应用」里加装或升级。
4. 下载来源：螺壳、引擎和应用在 GitHub Releases（luokelabs/luoke-releases），模型在 ModelScope 和 Hugging Face（两处先测速，挑快的下）；每个文件带哈希，核对后才用。

## 隐私（用户能核对的说法）

- 模型只在这台 Mac 上跑；邮件、打的字、记忆都在本机。螺壳联网只做两件事：检查更新（GitHub，默认开，「检查更新」窗口底下的「每天自动检查」能关）和下载模型、引擎、应用（上面那几处）；从 beta1.1 起，按流量计费的网络上不自动下。没有遥测和崩溃上报。
- 送进模型的文字只在内存里；螺壳的日志只记元数据（哪个任务、多少 token、多少秒），导出的诊断信息也是。
- 应用之间通过螺壳用模型、通过记忆共享理解；记忆归用户，应用之间不互相读对方的原始记录。
- 底线（顶层 ADR 0007）：数据只在用户自己的设备之间流动、端到端加密，不依赖能读到内容的云服务。

## 卸载

- 卸载一个应用：「应用」窗口里那一行的「…」→「卸载」；卸载整个螺壳：设置 › 关于 →「卸载螺壳」。都先列出会删什么再删。默认保留数据，勾选后才删应用声明的数据；可以选"同时从记忆里忘掉这个应用写的记录和理解"。输入法要先在「系统设置 → 键盘 → 输入法」里移除，卸载界面会带你去。
- 卸载螺壳会先卸掉所有应用，再删掉螺壳的模型、引擎、日志（`~/Library/Application Support/luoke-core`），注销登录项，把螺壳移到废纸篓。
- 记忆文件 `~/.luoke/mem.db` 归用户，任何卸载都不删，由用户自己决定。

## 常见问题（候选）

- 要多大内存：16 GB 起、推荐 32 GB 以上；各档区别见上表。
- 要下载多大：16 / 32 GB 档约 7 GB，64 GB 以上约 28 GB。
- 会不会上传：不会；螺壳只在检查更新和下载时联网。日志和诊断只有元数据（哪个任务、多少 token、多少秒）；空闲任务的输出摘要也在诊断里，各应用保证里面没有用户内容。
- 电池：默认用电池时不做后台任务，可以在设置里打开。
- 能不能自己选模型：不能，也不用；实验室按档位配好，每个选择有实测（实验室栏目）。
